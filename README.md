# Berlin data portfolio

Projects built around real working-student and internship openings in Berlin, grouped by the business domain they belong to. Each project lives in its own folder with its own README, tests, data generator and Colab notebooks.

All data is synthetic and generated by code in the project, with pseudonymous IDs only, and no personal data is collected or stored, in line with the GDPR and the German BDSG. Amounts are in euros and the settings are German, Austrian or Swiss.

## How the projects are built

- One folder per project: `<domain>/<project>/` with `src/`, `sql/`, `notebooks/`, `tests/`, `data/` and `outputs/`.
- Fixed random seeds, so every number in a README can be regenerated with one command.
- GitHub Actions runs each project's tests and its full pipeline on every push.
- Notebooks clone this repo when opened in Google Colab, so the Colab links work without setup.

More domains will be added here as projects are finished.
